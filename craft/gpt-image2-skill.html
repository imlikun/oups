一、为什么需要它

直接调 OpenAI 的 gpt-image-2 出一张图，要自己拼 API、管参数、写脚本存文件——零散且不好复用。而很多人真正要的，是「一句命令出图、改图、局部重绘」，最好还能在 Claude Code / Codex 里让 Agent 自动帮你生图。GPT Image2 Skill 就是把这套流程包好的开源技能包。

本文交付物

讲清这个技能包到底包含什么（案例库 + CLI + Agent 集成）、怎么装、怎么跑，以及它和本栏目另一篇「900+ 模板提示词库」的关系与区别。

二、它是什么

GPT Image2 Skill 是面向 OpenAI gpt-image-2 模型的「提示词画廊 + 命令行 + Agent 集成」三件套，本质是一层好用的封装，不是新的生图模型。它把零散的 API 调用收敛成可复用的提示词与一条脚本化的 CLI。

图 1：案例库 → CLI/技能 → OpenAI 接口的调用链路。

和「900+ 模板提示词库」不是同一个东西

本栏目此前发过 GPT Image 2 开源提示词库（900+ 模板），那是另一个仓库的纯提示词集合；本文是 wuyoscar/gpt_image_2_skill——一个带 CLI 与 Agent 集成的工具包。两者互补：词库负责「有什么好提示词」，技能包负责「怎么一键跑起来」。

三、核心能力

三块能力，对应三种使用姿势：

1162 条精选案例

覆盖科研配图、UI 原型、字体排版、摄影、动漫、地图、产品图等类别，直接复制即用，省去自己凑提示词。

2脚本化 CLI

支持尺寸/画质预设、批量出图（-n）、指定输出文件（-f）、参考图编辑（-i）与蒙版重绘（-m），可写进流水线批量生成。

3Agent 集成

提供 Claude Code 插件、Codex 安装、以及手动 agent-skill 软链三种方式，让 coding Agent 在任务里直接调它生图。

参数取值说明
-p, --prompt文本提示词（必填）
-f, --file路径输出文件名（默认时间戳）
-i, --image路径（可多次）参考图，触发 /v1/images/edits；多张可合成
-m, --maskPNG（含 alpha）蒙版：透明=重绘区域，需配合 -i
--size1k/2k/4k/portrait/landscape/square…尺寸预设，自定义须 16 倍数、最长边 ≤3840
--qualityauto/low/medium/high画质预算档：low 草稿、high 终稿
-n, --n整数批量生成数量

四、动手跑通

配置只需一行：把 OpenAI Key 放进环境变量或 ~/.env。无需其他设置。

# 配置密钥（必填，且是付费 Key）
export OPENAI_API_KEY="sk-..."

三种装法，按使用频率选：

# 方式 A：临时跑，不安装（最快）
uvx --from git+https://github.com/wuyoscar/gpt_image_2_skill gpt-image -p "a cat astronaut"

# 方式 B：永久装到 PATH
uv tool install git+https://github.com/wuyoscar/gpt_image_2_skill
gpt-image -p "a cat astronaut"

# 方式 C：接 Claude Code
/plugin marketplace add wuyoscar/gpt_image_2_skill
/plugin install gpt-image@wuyoscar-skills

三种生图姿势的实战示例：

# 1) 文生图：带尺寸与画质
gpt-image -p "neon-lit Tokyo alley at midnight" --size portrait --quality high -f tokyo.png

# 2) 参考图改图（可多张合成）
gpt-image -p "put the dog next to the woman, match lighting" -i woman.png -i dog.png --quality medium -f out.png

# 3) 蒙版重绘：透明区=重绘
gpt-image -p "replace sky with aurora" -i photo.jpg -m sky_mask.png -f aurora.png

五、适合谁 & 怎么挑

三类人最划算：设计师/开发者要快速出 UI 与产品图原型、科研党要画示意配图、自动化工程师要把生图塞进 Agent 流水线。如果你只是想要「好提示词抄」，那篇 900+ 词库更轻；想要「一键跑、还能接 Agent」才选这个技能包。

成本提醒（务必看清）

它只是封装，底层调用 OpenAI gpt-image-2 按张计费——--quality high 比 low 贵。自己准备并付费 OpenAI API Key，不是「装了就免费出图」。批量（-n）前先用 low 草稿验证提示词。
