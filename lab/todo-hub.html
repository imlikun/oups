wb-todo-hub 跨窗口任务管理

在任意 WorkBuddy 对话窗口里管任务：新建 / 查看 / 修改 / 删除，跟踪进度、计划、节点， 设相对或绝对时间提醒，每个任务还能写一份独立文档。配套一个可交互网页看板，把任务变成一张「依赖关系图」。

它能做什么

一个对话框，搞定全套任务流转

增删改查

说「记到待办：…」就建任务，分配 T 编号；「删任务 T003」一键移除索引与文档。

进度 / 节点 / 计划

进度手动设或由节点完成度推导；每个任务一份独立文档，写计划、节点清单、笔记。

时间提醒

「三天后」「下周一10点」都能设；相对时间自动换算绝对时间，建一次性或周期提醒。

可交互看板

网页看板按项目分组、按时间先后连线；节点小框可点击勾选，进度环实时重算。

跨窗口唯一

所有对话共享同一任务索引，ID 全局递增，不会再出现「这个窗口不知道那个窗口的任务」。

纯本地 / 零依赖

数据存本地文件，不依赖任何外部连接器；看板是纯静态 HTML，能挂任意静态空间。

三步上手

装好就能用

解压并安装

把包解压到 ~/todo-hub/，运行初始化脚本装技能：

# macOS / Linux
bash ~/todo-hub/setup-mac.sh

Windows：把 skill/wb-todo-hub/ 复制到 %USERPROFILE%\.workbuddy\skills\wb-todo-hub\ 即可。

在对话框里说一句话

任意 WorkBuddy 对话窗口输入：

记到待办：重构个人站首页
看待办
T001 进度 40%

技能会自动分配编号、写索引和文档。

生成看板（可选）

想看图就重跑生成脚本，浏览器打开产物：

# 生成 ~/.workbuddy/task-board.html
python ~/todo-hub/skill/wb-todo-hub/scripts/generate_board.py
看板里每个节点前面的小框可以直接点击勾选，进度环会实时重算；勾选存在浏览器本地，刷新不丢，点「复制更改」可贴回对话框写入数据源。
